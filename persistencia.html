Persistencia en el Navegador

En el mundo de la ingeniería de software, Persistencia se refiere a la capacidad de los datos de sobrevivir en el tiempo, incluso si el programa se cierra, el ordenador se apaga o, en este caso, el usuario refresca la página o cierra la pestaña. ## El Gran Mapa de la Persistencia en el Navegador

1. Persistencia Temporal (Session Scope)

Los datos viven estrictamente mientras la pestaña o ventana del navegador esté abierta. Si el usuario recarga la página, los datos se mantienen; pero si cierra la pestaña o la ventana, los datos se destruyen por completo inmediatamente. Además, los datos no se comparten entre diferentes pestañas, aunque sea el mismo sitio web.

  • Herramienta: SessionStorage.
  • Capacidad: ~5 MB.
  • Uso común: Guardar el estado de un formulario largo mientras el usuario navega entre pasos, o el estado de un carrito de compras temporal.

2. Persistencia Local Semi-Permanente (Local Scope)

Los datos no se borran cuando se cierras la pestaña, el navegador o incluso si se apaga la computadora. Solo desaparecen si el usuario limpia manualmente el historial/caché del navegador o si el código de JavaScript los elimina explícitamente.

  • Herramienta: LocalStorage.
  • Capacidad: ~5 MB a 10 MB.
  • Uso común: Recordar si el usuario prefiere el modo oscuro o claro, guardar la última canción reproducida o las preferencias de idioma de la interfaz.

3. Persistencia Masiva (Database Scope)

Es el sistema de almacenamiento más avanzado y potente que incluye el navegador. A diferencia de los anteriores, no guarda texto simple en formato clave: valor, sino que es una completa base de datos no relacional orientada a objetos que permite almacenar grandes volúmenes de datos estructurados (archivos, objetos complejos, arreglos). Además, funciona de forma asíncrona para no congelar la interfaz de la página. Está diseñada para aplicaciones web complejas que necesitan funcionar sin internet (Offline) o que manejan miles de registros y archivos pesados.

  • Herramienta: IndexedDB.
  • Capacidad: Enorme (desde cientos de megabytes hasta gigabytes, dependiendo del espacio libre en el disco duro del usuario).
  • Uso común: Aplicaciones de edición de fotos/video online, aplicaciones de notas estructuradas que guardan archivos, videojuegos web que guardan partidas pesadas o aplicaciones web progresivas (PWAs) que funcionan offline.

IndexedDB es la joya de la corona dentro de la Persistencia en el Navegador. Es la única que rompe la barrera de los textos simples de pocos megabytes para darte el poder de una base de datos real.

A diferencia de las cookies, los datos guardados con Session Storage, Local Storage o IndexedDB nunca se envían al servidor de forma automática y se manejan puramente a través de JavaScript en el navegador.

4. Persistencia en el Navegador vinculada al Servidor (Network Scope)

Este tipo de persistencia se maneja con cookies las cuales son el método de almacenamiento más antiguo de la web. Las cookies son pequeños fragmentos de texto que el navegador guarda y, aquí está su característica clave, se envían automáticamente al servidor en cada petición HTTP que realizas a ese sitio web. Tienen fecha de caducidad obligatoria.

  • Herramienta: Cookies (document.cookie).
  • Capacidad: Muy limitada (~4 KB).
  • Uso común: Autenticación y seguridad (saber si has iniciado sesión), seguimiento de usuarios (analíticas) y personalización básica. Debido a que viajan al servidor en cada clic, usarlas para guardar datos grandes ralentiza la web..
