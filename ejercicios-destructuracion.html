Ejercicios Destructuración

Copia los snippets de los ejercicios y complétalos:

Ejercicio 1: El perfil de usuario (Objetos)

Tienes el siguiente objeto que representa a un usuario. Extrae las propiedades nombre, edad y pais en variables independientes usando una sola línea de código.

Ejercicio 2: El podio de una carrera (Arrays)

Tienes un array con los nombres de los corredores en el orden en que llegaron a la meta. Extrae al primer, segundo y tercer lugar en variables llamadas oro, plata y bronce.

Ejercicio 3: Configuración de una app (Valores por defecto)

Al recibir las opciones de configuración de una aplicación, a veces faltan datos. Extrae tema e idioma del siguiente objeto. Si idioma no existe en el objeto, debe tomar el valor por defecto "es" (español).

Ejercicio 4: Conflicto de variables (Alias / Renombrar)

Imagina que estás importando datos de una API externa que usa nombres en inglés (title y salary). Extrae esos valores pero cámbiales el nombre a variables en español (titulo y salario) para que "encajen" con tu código.

Ejercicio 5: Datos anidados de un e-commerce

A veces los objetos tienen otros objetos dentro. Extrae el pais y la ciudad de la dirección de este cliente, además de su nombre, todo en una única línea de destructuración.

Ejercicio 6: El producto y el resto (Operador Rest ...)

Tienes un producto de una tienda. Extrae el id y el precio en variables individuales, y agrupa todas las demás propiedades restantes en un nuevo objeto llamado detalles.
