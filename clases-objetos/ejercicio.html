Ejercicio CRUD - Edificios (sin herencia)

Crear una aplicación que permita gestionar la limpieza de los edificios de una empresa de Servicios Varios.

La aplicación contendrá una clase Edificio con los siguientes datos: nombre, número de plantas y superficie (m²) que se darán al crear el edificio. Una vez creado el edificio, el único atributo que se puede modificar es la superficie del mismo. El resto se puede acceder sólo para leerlos.

  • Al crear un objeto (new Class): Se pueden pasar tantos datos como requiera el constructor, sin importar si van a terminar en variables públicas o privadas.
  • Una vez creado el objeto: El programa ya pierde el acceso directo a los atributos privados (#). A partir de este momento, solo la propia clase puede leerlos o modificarlos.

La clase tendrá un método limpiar() en la clase pertinente, el cual mostrará por pantalla el tiempo que se ha tardado en limpiar el edificio, teniendo en cuenta que se tarda en limpiar un minuto por cada 5 m².

Además, si un edificio tiene más de una planta, se tarda en subir medio minuto de una planta a otra. Por lo tanto, añadiremos medio minuto por cada planta adicional. Por cada minuto de trabajo se pagará un euro diario. Tener en cuenta que, como se limpia cada día, para obtener el coste mensual, tendremos que multiplicar por 30 (este coste mensual también se deberá mostrar por pantalla al ver los datos de un edificio).

La aplicación deberá ser capaz de: agregar, modificar la superficie, eliminar y devolver los datos de un edificio, además de imprimir la lista de todos los edificios gestionados. También se deberá poder conocer el estimado en coste mensual, por concepto de limpieza, de todos los edificios.

Truco: Llenad con unos 3-4 datos de prueba el array de edificios para probar el programa más cómodamente
