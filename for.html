Bucle for

El bucle for permite repetir un número de veces determinado un bloque de código.

El bucle for se utiliza cuando sabemos el número de iteraciones (vueltas) que el bucle debe ejecutarse.

El bucle for siempre debe tener un inicio, un final y un incremento. El incremento puede ser positivo o negativo.

Ejemplos (abre la consola y verás el resultado):

Muestra en la consola los números pares del 0 al 10

for (let i=0; i<=10; i+=2) {
  console.log(i);
}

Muestra en la consola los números de 5 en 5 de forma descendente comenzando en 25

for (let i=25; i>=0; i-=5) {
  console.log(i);
}

Recorre la letras de la palabra 'JavaScript'

let palabra ='JavaScript';
console.log(palabra);
for (let i=0; i<palabra.length; i++) {
  console.log(palabra[i]);
}
