Ejercicios con arrays de objetos

Cambiar los ejercicios que hemos hecho con arrays simples a arrays de objetos de la siguiente manera:

Ejercicio 6.1. Mes de número a letra

Haz un programa que:

  1. Guarde los meses del año en un array de objetos denominado mesescon los siguientes atributos: numeroMes, mesLetra, numeroDias. Ejemplo:

    { numeroMes:1, mesLetra: 'enero', numeroDias: 31 }
  2. Pregunte al usuario/a un mes entre 1 y 12 y lo guarde en una variable llamada mesNumero. Ejemplo para mesNumero === 5
  3. Busque el mes indicado por el usuario en el array meses
    • const indice = meses.findIndex(mes => mes.numeroMes === mesNumero);
  4. Muestre el siguiente mensaje: «El mes x se corresponde con xxx y tiene xx días.».

Ejemplo: «El mes 5 se corresponde con mayo y tiene 31 dias»

Ejercicio 6.2. Lista de Compras

Cambia el array carrito para que en vez de guardar un array simple guarde un array de objetos que indique producto y precio. (Al mostrarlo en pantalla deberá mostrar por ejemplo: 0. PAN, €2.35 etc…)

Agregar un botón que recorra el array de objetos con un bucle for-of e indique el total de la lista de compras.

Ejercicio 6.3. Tareas

Cambiar el array tareas para que sea un array de objetos que guarde, además de la tarea, su importancia (urgente, alta, media, baja) y la fechaTope para realizarla.

Preguntar la importancia de la tarea con un control select y su fechaTope con un control de tipo date .

Para buscar en un array de objetos en JavaScript, los métodos principales son find, filter y findIndex.

  1. find(): Retorna el primer objeto que cumple con la condición especificada, o undefined si no se encuentra ninguno. Es ideal cuando solo necesitas un objeto único. Ejemplo: const persona = personas.find(p => p.nombre === 'Pepito');
  2. filter(): Retorna un nuevo array con todos los objetos que cumplen la condición. Úsalo cuando esperes múltiples resultados. Ejemplo: const tareasUrgentes = tareas.filter(t => t.importancia === 'Urgente');
  3. findIndex(): Similar a find, pero retorna el índice (posición) del primer objeto que cumple la condición, o -1 si no existe. Ejemplo: const indice = personas.findIndex(p => p.nombre === 'Pepito');
